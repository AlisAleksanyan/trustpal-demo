# TrustPal Impact Agent

The agent ranks eligible causes, structures volunteer evidence, and turns a creator's idea into a reviewable cause plan. It cannot award Trust Points, approve recipients, or move money autonomously. People approve recommendations, approved stewards verify work, and PayPal performs every monetary transaction.

The frontend includes AG Grid decision surfaces so judges and contributors can inspect funding gaps, skill needs, model reasons, allocations, and PayPal recipient readiness.
